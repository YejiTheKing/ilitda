# 가상 자료

개발과 테스트에 쓰는 자료다. 실제 사업장, 실제 고객, 실제 금액은 들어 있지 않다.
`scripts/make_sample.py`로 다시 만들 수 있다. 실제 사업장에서 받은 자료는 `data/real/`에 두고 저장소에 올리지 않는다.

## 거래처등록_견적

가상의 소규모 부품 가공 업체. 업무: 신규 거래처 등록부터 첫 견적서 발행까지. 전임 담당자가 남긴 파일을 흉내 냈다.
