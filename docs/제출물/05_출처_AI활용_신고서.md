## 2. LLM·외부 API

| 구분 | 내용 |
|---|---|
| 모델 | Claude Opus 5.5 (`claude-opus-5-5`), Anthropic API. 코드 기본값 `src/ilitda/llm/client.py` `DEFAULT_MODEL`, 환경변수 `ILITDA_MODEL`로 변경 가능 |
| 계정·비용 | 개인 계정, 개인 비용. 10/1 연결. 이 PC에 설정된 다른 용도의 `ANTHROPIC_BASE_URL`이 쓰이지 않도록 공식 주소를 코드 기본값으로 고정하고 `ILITDA_API_BASE_URL`로만 바꿀 수 있게 했다 |
| 용도(호출 5종) | 목표 해석(parse_goal), 계획 수립(make_plan), 변경 유형·영향 분류(classify_changes), 절차 복원(extract_procedure), 체크리스트 생성(build_checklist). 모두 JSON 스키마 강제 출력, 스트리밍 호출 |
| 호출 기록·재생 | 실제 호출 때 요청·응답·토큰 수·모델명을 `runs/_llm_cache`에 저장. 같은 입력(모델·system·user·schema 해시)이면 저장 응답을 재생하고 실행 로그에 `replay=true`와 모델명을 남긴다. API 장애·현장 네트워크 장애 대비 용도. 시연영상에 재생 구간이 있으면 자막으로 밝힌다 |
| 실측 사용량 | 가상 자료 1회 완주: 입력 약 6천·출력 약 9천 토큰, 약 0.2달러(10/2). 두 번째 실행은 재생으로 호출 0회. 되물음 반복 사고 1건: 24회 연속 호출 약 0.2달러(10/3, 이후 되물음 최대 2회·기본값으로 수정). 공개 테스트는 하루 80회 한도 |
| 전송 전 처리 | LLM에 보내기 전 형식 기반 가림 7종(주민등록번호·사업자등록번호·전화·계좌·이메일·차량번호·주소), 가린 건수를 로그에 기록. 형식이 없는 이름·회사명은 자동으로 못 잡으므로 실제 자료는 치환표 기반 가명 사본을 따로 만들어 사용(4절) |
| 사실대로 적는 것 | 실제 자료 A의 담당자 검토 실행 1회(10/3 새벽, 실행 `20261003-014402`)는 가명 처리 **전** 원본으로 비공개 실행했다. 이후의 모든 실행·제출물은 가명 사본만 사용 |
| 그 외 외부 API | 없음. 검색·메일·메신저·업무시스템 연동 없음. 알림은 화면 내 로그 기록만 |

## 3. 오픈소스 패키지

직접 사용한 패키지(9/30 설치 기준). 간접 의존성을 포함한 전체 목록과 버전은 `requirements.lock.txt`에 있다. 라이선스는 각 패키지 배포 정보에 적힌 값이다.
