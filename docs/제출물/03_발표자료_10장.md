원칙: 제목은 항목 이름 한 줄(문제상황·핵심기능·차별성…), 본문은 숫자·상자·그림 같은 증거만, 한 장에 한 생각, 글자 16pt 이상. 설명은 발표자 노트(대본)로 말한다. 라벨 칩은 주관사 권장 6구간 이름이다.
권장 구간과 시간: 문제 30초(장 1~2) → Agent 설명 1분(장 3~4) → 구조 1분(장 5~6) → 실제 시연 2분 30초(장 7) → 성과 30초(장 8) → 발전계획·비즈니스모델 30초(장 9~10) = 6분. 영상은 2분 59초라 발표 때는 1.2배속 또는 마지막 실행 로그 장면(2:41~)을 생략해 2분 30초에 맞춘다. 질의응답 2분은 장 10으로 받는다.
형식: **라벨** / **제목** / **숫자**(값 | 설명) / **키워드**(글머리) / **열**(제목 | 내용) / **그림** / **대본**.

## 장 3. 핵심기능 [심사 1 · 2 · 3] (35초)

**라벨**: Agent 설명

**제목**: 목표 · 역할 · 핵심기능

**키워드**
- Agent Goal — 섞인 폴더 하나로 신규자가 첫 업무를 끝내고 책임자가 승인한다
- 역할 — 에이전트는 복원·검증·질문, 책임자는 답변·승인, 신규자는 수행

**열**
- F1 최신본 판별·변경점 | 수정 날짜가 아니라 내용으로. 판별 근거를 보여 준다
- F2 절차 복원·근거 확인 | 단계마다 문서명·원문 인용·행 번호. 원문에 없으면 안 보여 준다
- F3 충돌·빈틈 확인 | 단정하지 않고 책임자에게 묻는다. 모르면 '미확정'
- F4 인계 진행·완료 판정 | 체크리스트 → 수행 → 승인 → 판정. 보류하면 보완 뒤 재승인
- F5 인수인계서 생성 | 승인된 절차와 '확인할 것'을 Word 문서로. 신규자가 들고 일하는 매뉴얼

**대본**
목표는 하나입니다. 섞인 폴더 하나로 신규자가 첫 업무를 끝내고 책임자가 승인하는 것. 에이전트는 복원하고 검증하고 묻고, 책임자는 답하고 승인하고, 신규자는 수행합니다. 기능은 다섯입니다. 최신본을 가리고, 근거 있는 절차만 복원하고, 모르는 건 묻고, 체크리스트로 승인까지 추적하고, 마지막에 인수인계서를 문서로 만듭니다.

## 장 4. 차별성 [심사 4] (25초)

**라벨**: Agent 설명

**제목**: 차별성

**열**
- 최신본을 내용으로 판별 | 수정 날짜는 복사만 해도 바뀐다. 개정번호 → 날짜 → 수정 표시 → 추가분 순으로 가리고, 모르면 묻는다
- 근거 실존을 코드로 확인 | AI가 인용한 문장이 원문에 있는지 대조한다. 없으면 신규자에게 보여 주지 않는다
- 승인까지 완료 추적 | 질문 → 답변 → 체크리스트 → 승인 → 판정 → 인수인계서. 인계가 끝났는지가 기록으로 남는다

**키워드**
- 범용 AI는 최신본을 안 가리고 근거를 지어내며 끝났는지 모른다 · 위키·RAG는 누군가 써 둬야 한다 · 인수인계서 양식은 담당자가 떠나면 쓸 사람이 없다

**대본**
그냥 파일을 AI에 올려 물어보는 것과 세 가지가 다릅니다. 첫째, 어느 파일이 최신인지 내용으로 가립니다. 둘째, AI가 든 근거가 원문에 실제로 있는지 코드로 확인합니다. 셋째, 절차를 보여 주고 끝이 아니라 승인과 인수인계서까지 갑니다. 담당자가 이미 떠난 뒤에도 책임자 확인만으로 성립하는 게 핵심입니다.

## 장 10. 한계·발전계획 [심사 5 · 7] (15초)

**라벨**: 발전계획 · 비즈니스모델

**제목**: 한계 · 현장 적용 전 보완점

**열**
- 한계 | 실행 순서 고정·재계획 없음 · 근거 확인은 글자 일치 · 사진·스캔 미지원 · 역할별 로그인 없음 · 표본 소수
- 현장 적용 전 보완 | 역할별 로그인·알림 → 스캔 OCR → 재계획 → 블라인드 평가·범용 AI 비교 → 업무 초안·이해 확인 문답

**대본**
한계입니다. 자료에 없는 단계는 만들지 않아서 책임자가 채워야 하고, 근거 확인은 글자 일치라 의미 왜곡은 못 잡습니다. 지금은 한 사이트에서 두 역할을 번갈아 쓰지만 현장에서는 역할별 로그인으로 나눌 겁니다. 질문 주시면 이 한계부터 답하겠습니다. 고맙습니다.
(예상 질문 — "모델을 학습시켰나?") 학습은 하지 않았습니다. 범용 LLM을 다섯 번 호출하고, 신뢰성은 학습이 아니라 근거 실존 확인과 책임자 확인으로 확보했습니다. 최신본 판별과 근거 검증을 일부러 코드로 둔 이유도 같습니다. AI가 지어낸 근거를 잡아내려면 판정자가 AI가 아니어야 합니다.
