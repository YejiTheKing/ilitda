# 온라인 테스터 모집·안내

## 모집 글 (10분) (카톡·커뮤니티)

```
[10분만 써 보실 분] 인수인계 AI 테스트 (경남 AI 경진대회 출품작)

담당자가 갑자기 그만뒀을 때, 남은 파일만 보고 신입이 일을 이어받게 돕는 AI를 만들었습니다.
아래 링크에서 10분만 써 보고 한 줄 평을 남겨 주시면 됩니다.
준비된 가상 회사 자료로 해 봐도 되고(어떤 회사·어떤 파일인지와 답할 때 볼 '정답 메모'가 화면에 있습니다), 본인 직장의 빈 양식·절차 메모를 올려서 "내 업무를 제대로 복원하나" 직접 확인해 봐도 됩니다 (고객정보는 빼고요).

링크: [공개 주소]
안내: 링크 첫 화면에 순서가 있습니다. 회원가입·설치 없음. PC 브라우저 권장.
기간: 10/5(일) 밤까지

남겨 주신 이름·소속(직무)·한 줄 평은 대회 제출 서류의 "사용자 검증"에 들어갑니다 (동의하신 분만).
올린 파일은 제 PC에만 저장되고 대회가 끝나면 삭제합니다. 회사 이름과 개인정보는 대회 영상·발표자료·보고서에 나오지 않습니다. 개인정보·고객정보는 임의 정보로 바꾸거나 제거해 주시고, 올려도 되는지 애매하면 사장님이나 상사 동의를 먼저 구해 주세요.
```

## 운영 방법

1. 터미널에서 `scripts/public_demo.sh` 실행 → `https://xxxx.trycloudflare.com` 주소가 뜸
2. 주소를 테스터에게 보냄. PC를 끄거나 터미널을 닫으면 링크가 죽음 (잠들지는 않게 해 둠)
3. 피드백은 `runs/feedback/`에 사람별 파일로 쌓임. 사이드바에는 안 보임
4. 끝나면 `Ctrl+C`. 주소는 다시 켜면 바뀜

## 안전장치

| 위험 | 대책 |
|---|---|
| 실제 자료 노출 | 공개 모드에서는 `data/sample`만 보임 |
| 남의 실행 열람 | 공개 모드에서는 자기 세션의 실행만 보임 |
| API 비용 폭주 | 하루 AI 호출 80회 한도 (약 8~10회 완주, 2~3달러). 기본 예시는 저장된 응답이라 비용 0 |
| 링크 유출 | 주소가 무작위이고, 끄면 사라짐. 테스터에게만 전달 |
| 테스터가 올린 파일 | 세션별 폴더 `runs/uploads/<실행 ID>/`에만 저장(저장소 제외). 동의 체크 없이는 시작 불가. 20개·각 10MB 한도. 전화·주소·번호 형식은 가린 뒤 전송. **대회 후 폴더째 삭제** |
| 개인정보 입력 | 안내문과 업로드 화면에 고객정보 제외를 명시 |

## 확인서로 만들기

피드백 파일에는 이름, 소속, 날짜, 사용 시간, 좋았던 점, 불편한 점, 사용 의향(1~5), 동의 여부가 들어 있다.
제출 때 `scripts/feedback_report.py`(작성 예정)로 표를 만들어 보고서에 붙인다. 서명이 필요하면 카톡 답장 캡처로 대신한다.
