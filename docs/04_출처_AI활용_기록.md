## 2. LLM·API

| 이름 | 용도 | 비고 |
|---|---|---|
| Claude Opus 5.5 (`claude-opus-5-5`, Anthropic API) | 목표 해석(parse_goal), 계획 수립(make_plan), 변경 유형·영향 분류(classify_changes), 절차 복원(extract_procedure), 체크리스트 생성(build_checklist) — 호출 5종, 모두 JSON 스키마 강제 출력 | 개인 계정, 개인 비용. 10/1 연결. 코드 기본값 `src/ilitda/llm/client.py` `DEFAULT_MODEL`, 환경변수 `ILITDA_MODEL`로 변경 가능 |

- API 주소: 이 PC에 설정된 다른 용도의 `ANTHROPIC_BASE_URL`이 쓰이지 않도록 공식 주소를 코드 기본값으로 고정하고 `ILITDA_API_BASE_URL`로만 바꿀 수 있게 했다(10/1, `llm/client.py`).
- 호출 기록·재생: 실제 호출 때 요청·응답·토큰 수·모델명을 `runs/_llm_cache`에 저장한다. 같은 입력(모델·system·user·schema 해시)이면 저장 응답을 재생하고 실행 로그에 `replay=true`와 모델명을 남긴다. API 장애·현장 네트워크 장애 대비 용도.
- 실측 사용량: 가상 자료 1회 완주 입력 약 6천·출력 약 9천 토큰, 약 0.2달러(10/2). 두 번째 실행은 재생으로 호출 0회. 되물음 반복 사고 1건으로 24회 연속 호출 약 0.2달러(10/3, 이후 되물음 최대 2회로 수정). 공개 테스트는 하루 80회 한도.
- 그 외 외부 API: 없음. 검색·메일·메신저·업무시스템 연동 없음.
